## Что из этого следует

Бот целиком в GitHub Actions по `docs/spec.md` §5 работать не сможет: обход сайта нужно делать с адреса,
который Cloudflare пускает. Варианты (ничего из этого не делалось — решать владельцу):

1. **Self-hosted runner GitHub на машине владельца** (Mac или другой всегда включённый компьютер с домашним
   интернетом): workflow, секреты, состояние — как в спеке, но задачи идут с домашнего IP. Минус — машина должна
   быть включена; плюс — почти весь план и код остаются как есть.
2. **Запуск бота прямо на компьютере владельца** (launchd/автозапуск), без Actions. Проще, но тоже нужен
   включённый компьютер и интернет.
3. **VPS/облако** — не проверено: адреса дата-центров Cloudflare часто режет так же, нужна своя проба.
4. **Спросить у somon.tj доступ** (белый список / официальный фид) — долго, не от нас зависит.

Код бота (логика `lib/somon`, `lib/market`, `lib/core`, Telegram, состояние) от выбора почти не зависит —
меняется только «где крутится» и путь хранения состояния. Проба остаётся в репо: повторить —
Actions → probe → Run workflow.
