# qwe-bot — правила проекта

Что строим: `docs/spec.md`. Это источник правды; если находишь в ней ошибку или пробел — исправь
спеку и коротко скажи владельцу, что изменил и почему.

## Общение
- Владелец пишет по-русски (часто транслитом). Отвечать по-русски, простыми словами, отчёт 4–8 строк.
- Не говорить «готово», пока не проверено командой/логом. Непроверенное так и называть: «не проверено».

## Машина (MacBook M5 Pro, 24 ГБ, интернет — раздача с телефона)
- Dart: `~/flutter-sdk/bin/dart` (идёт с Flutter 3.47.2). Эмулятор и телефон этому проекту не нужны — не трогать.
- Ничего больше ~1 ГБ не скачивать (мобильный интернет).
- `/tmp` чистится сам — важное туда не класть. В PATH первым стоит GNU `stat`. `pgrep -f` находит и сам
  Claude (его argv) — фильтровать.

## Соседи (не мешать друг другу)
- `~/Projects/qwe` — приложение, там пишет сессия qwe-v2. Её папку ТОЛЬКО ЧИТАТЬ: файлы, `git -C ~/Projects/qwe
  show/archive/tag -l`. Ничего там не писать, не коммитить, не запускать там flutter/dart-команды, меняющие файлы.
- `~/Projects/qwe-market` — только читать.
- `~/telegram-zip-bot` — пример рабочего бота владельца на GitHub Actions. Только читать.

## Безопасность
- Репозиторий github.com/osimmoapies/qwe-bot — ПУБЛИЧНЫЙ (иначе Actions не бесплатны). В git и в логах Actions
  — никаких секретов и личных данных продавцов (имена, телефоны, описания). Логи — счётчики и статусы.
- Секреты уже заведены (osim-b9): secrets `BOT_TOKEN`, `STATE_KEY`; variable `OWNER_ID`. Локальные копии
  `~/.qwe-bot/{token,state_key,owner_id,username}` — читать из файла прямо в код/переменную окружения процесса;
  НИКОГДА не печатать, не `echo`, не `cat`, не в логи, не в git. Новых токенов/ключей не создавать. Личные токены
  владельца (`gh auth token` и т.п.) в секреты не класть.
- Не клонировать незнакомые репозитории, не качать архивы с кодом. Зависимости — только популярные пакеты
  pub.dev; actions — только официальные (`actions/*`, `dart-lang/setup-dart`), с закреплённой версией.
- somon.tj: только публичные страницы, ≤ 1 запрос в 1,5 с, без `/api`. Ничего не покупать, продавцам не
  писать, не логиниться.
- Telegram: бот пишет только владельцу (`OWNER_ID`). Аккаунт владельца (Telethon и т.п.) не использовать.
  Тестовых сообщений владельцу — не больше 10 за всю работу, с пометкой «🧪 тест».

## Работа
- Субагенты / Agent / Task / Workflow — запрещены (владелец). Модель не менять (только Opus 5.5).
- TDD, коммиты по шагам. Push в osimmoapies/qwe-bot разрешён (владелец выбрал бота в облаке GitHub).
  Force-push — только в служебную ветку состояния.
