# qwe-bot — спецификация (владелец попросил 2026-10-13, выбрал GitHub Actions)

Telegram-бот **@qwe_deals_bot** работает 24/7 в GitHub Actions (публичный репозиторий
`osimmoapies/qwe-bot`). Он сам следит за новыми объявлениями о телефонах на somon.tj и сразу присылает
владельцу выгодные — красивой карточкой с фото и кнопками, чтобы успеть купить дёшево и перепродать.
Бот личный: отвечает только владельцу (`OWNER_ID`); остальным — одна строка «Это личный бот» и всё.

Он — второй канал рядом с Android-приложением qwe (`~/Projects/qwe`). Состояние у них раздельное.

## 1. Логика — та же, что в приложении (одна правда)

- Разбор страниц, нормализация моделей, рынок, выгода, предупреждения, метки IMEI — код приложения:
  папки `lib/somon`, `lib/market`, `lib/core` из `~/Projects/qwe`, скопированные КАК ЕСТЬ с git-тега
  `core-vN` (сейчас ждём `core-v2`). Руками копию не править — только пересинхронизация скриптом
  `tool/sync_core.sh`; файл с тегом, коммитом и sha256 копии + тест, который их сверяет.
- Правила: спека приложения `~/Projects/qwe/docs/spec.md` §3–5 и §9: порог скидки 25 %, мин. прибыль
  300 c., перепродажа = медиана × 0,85, выборка (б/у 15, новый 5), предупреждения не шлются как выгодные;
  без метки IMEI — шлются с жёлтой меткой «IMEI не проверен» или «растаможен (со слов)».

## 2. Обход somon.tj

- Цикл примерно раз в 2 минуты (в настройках: 2/5/10 мин): страница, где платные смешаны с обычными, и начало
  блока «IMEI проверен», затем начало второго блока — обычные без метки, ≈ стр. 192; границу искать и
  запоминать, как приложение (`~/Projects/qwe/lib/sync/crawler.dart`), — до уже известных id. Чисто платные
  страницы в частом цикле не скачивать.
- Кандидат (по цене прошёл порог) → детальная страница (описание, IMEI, продавец, фото) → окончательная
  оценка → карточка.
- Рынок: полный сбор всех страниц (≈ 375) раз в сутки ночью по Душанбе (UTC+5) → медианы по ключам.
  При первом запуске — сразу полный сбор; пока рынка нет, карточки не слать (в /status виден прогресс).
- Вежливость: ≤ 1 запрос в 1,5 с, gzip, десктопный User-Agent (мобильный → 302 на m.somon.tj), таймауты,
  повторы с экспоненциальной паузой на сеть/5xx/429, без параллельных запросов к сайту.
- Если разметка сломалась (на странице с обычными объявлениями парсер нашёл 0) — одно сообщение владельцу
  «⚠️ сайт изменился, бот на паузе», без спама; повторная проверка раз в 30 мин.

## 3. Карточка выгодного объявления

`sendPhoto` (первое фото; если Telegram не берёт ссылку — скачать и загрузить файлом; фото нет — текстом),
`parse_mode=HTML`. Пример подписи:

```
🔥 <b>iPhone 13 · 128 ГБ</b> · б/у
💰 <b>1 499 c.</b>   рынок ≈ 4 000 c.
📈 выгода <b>+1 900 c.</b> · −63 %
📍 Душанбе · 🕐 3 мин назад · 👤 частник
🟡 IMEI не проверен
```

Метка: 🟢 «IMEI белый» / 🟡 «IMEI не проверен» / 🟡 «растаможен (со слов)». Цены в формате приложения
(«4 000 c.», узкий неразрывный пробел). Кнопки (inline): ряд 1 — «🔗 Открыть на Somon» (url); ряд 2 —
«⭐ Слежу», «🙈 Скрыть», «📊 Похожие». После нажатия — кнопка меняется на месте («✅ Слежу», «↩️ Вернуть»),
`answerCallbackQuery` с коротким текстом. «Похожие» — ответ: медиана, «половина — от … до …», 5 самых
дешёвых активных той же модели (ссылками).

Одно объявление — одна карточка. Повторно — только если цена снизилась: «📉 подешевело: 1 499 → 1 299 c.».
Несколько сразу — по одной карточке, без флуда (соблюдать лимиты Telegram, `retry_after`).

## 4. Слежка, команды, настройки

- «⭐ Слежу» → бот следит: «📉 цена снижена», «❌ продано/снято» (объявление пропало больше суток или 404).
- Команды (`setMyCommands`, по-русски): `/start` — приветствие + текущие настройки; `/top` — 10 лучших
  активных выгодных сейчас; `/watch` — слежка; `/settings` — inline-меню: порог скидки, мин. прибыль,
  бюджет (макс. цена), бренды, только частники, частота, тихие часы (по умолчанию выкл, 23:00–08:00; в тихие
  часы — `disable_notification`, карточка не теряется), пауза; `/status` — работает с …, последняя проверка,
  новых и выгодных за сутки, возраст рынка, сколько моделей.
- Вечерняя сводка в 21:00 по Душанбе: сколько новых, сколько выгодных, лучшая находка дня (можно выключить).
- Описание бота (`setMyDescription`, `setMyShortDescription`) — по-русски. Аватар уже стоит (иконка qwe).

## 5. Хостинг — GitHub Actions

> ⚠️ Проба 2026-10-13: раннерам GitHub somon.tj отвечает 403 Cloudflare «Just a moment...» — см. `STATUS.md`.
> Где крутить обход сайта — решает владелец; до решения раздел ниже не выполним как есть.

- Схема как у бота владельца FileBox (`~/telegram-zip-bot/.github/workflows/bot.yml`): cron каждые 5 мин +
  `concurrency` (без отмены идущего) + работа ≈ 5 ч 45 мин и мягкая передача следующему запуску. Простой при
  передаче — минимальный; ни одного колбэка/апдейта не терять (offset getUpdates хранить в состоянии).
- Состояние (виденные id, карточки, слежка, настройки, снимок рынка, граница второго блока, offset) —
  зашифрованный файл (AES-GCM, ключ — секрет `STATE_KEY`) в служебной ветке этого же репозитория; запись
  встроенным `GITHUB_TOKEN` (`permissions: contents: write`); ветку перезаписывать одним коммитом, чтобы репо
  не пухло. Сохранять периодически и перед выходом.
- Ловушка: GitHub отключает cron в публичных репо после 60 дней без активности — выяснить точное правило и
  встроить защиту (или хотя бы предупреждение владельцу в боте заранее).
- В логах Actions (они публичные) — только счётчики и статусы.
